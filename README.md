# 365日出荷予測

すててこ物流部向けの365日出荷予測アプリ初期版。

## 初期予測ロジック

- 2026/2/21〜2026/9/13の実績を初期学習期間として使用
- 通常日は曜日別に `今年実績合計 ÷ 前年実績合計` を成長係数として算出
- 5/0翌日・楽天SS波動は曜日別基準からのイベント補正倍率を算出
- 2026/9/14〜2027/2/20を再予測
- 配送比率は今年実績から自動算出
- 必要人数は初期値 `予測出荷件数 ÷ 180件/人` の切り上げ

## Supabase

既存の人時管理アプリと同じSupabaseプロジェクトを使用し、テーブル名を `forecast365_*` で分離します。

1. Supabase SQL Editorで `schema.sql` を実行
2. アプリへログイン
3. 初回ログイン時に `seed-data.js` の365日分を自動登録

RLSによりログインユーザー本人のデータだけを参照・更新します。

## 画面

- ダッシュボード
- 365日予測一覧
- 月次集計（20日締め）
- 日別実績入力 / 手動予測補正
- 予測精度
- 予測設定

実績入力後は曜日別成長率・イベント補正・配送比率を再計算し、未来日の予測を更新します。
